# Third-party licenses for the embedded Tailscale client

The embedded Tailscale client is a C reimplementation. Third-party components
included in the binary and their licenses:

- lwIP (BSD-3-Clause) — userspace TCP/IP stack
- wireguard-lwip (BSD-3-Clause) — WireGuard protocol and BLAKE2s
- nghttp2 (MIT) — HTTP/2 client
- libsodium (ISC) — X25519, ChaCha20-Poly1305, XChaCha20, NaCl box, CSPRNG
- Mbed TLS (Apache-2.0) — TLS 1.2 (already used by Moonlight-Switch)
- jansson (MIT) — JSON (already used by Moonlight-Switch)
- Mozilla CA bundle (MPL-2.0) — resources/tailscale/cacert.pem
- Protocol formats derived from reading the tailscale/tailscale sources
  (BSD-3-Clause); no Go code is included.
